
# FilmMate

FilmMate is an academic software development project built using **C# and .NET** as part of the **Software Verification and Validation** course at the Faculty of Electrical Engineering, University of Sarajevo.

The project combines application development with software quality assurance principles, emphasizing testing, verification, and validation.

## Technologies Used

- **Programming Language:** C#
- **Framework:** .NET
- **Development Environment:** Visual Studio
- **Version Control:** Git, Azure DevOps

## Project Highlights

- Object-oriented application development
- Software verification and validation
- Software testing and quality assurance
- Collaborative development and version control

## Academic Project

Developed as part of university coursework at the **Faculty of Electrical Engineering, University of Sarajevo**.
